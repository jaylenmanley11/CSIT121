My First Multipage Website!

This website showcases three common image formats used on the web: PNG, JPG, and GIF. Each example has its own page with an image description, information about the file type, why I chose the image, and source information.

I chose a funny cat reaction image for PNG, a colorful green-hill landscape for JPG, and a dancing banana animation for GIF. These examples make it easy to compare how different formats are used online.
