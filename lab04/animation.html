GIF Example: Dancing Banana

Image Description

This animated image shows a silly banana character dancing!

Image File Type

GIF stands for Graphics Interchange Format. It supports frame-based animation and is often used for short, looping animations and reaction images.

Why?

I chose this because funny looping animations are popular online, and GIF makes it possible to show simple movement without a video player.

Source
