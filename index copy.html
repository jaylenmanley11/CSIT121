My Blog Posts

Lab 02: HTML

In Lab 02, I learned how to use HTML to build a web page. I practiced using headings, paragraphs, links, and images. I learned that HTML gives a website its structure and helps organize the information on the page.

Lab 03: CSS

In Lab 03, I learned how to use CSS to change the look of a web page. I practiced changing colors, fonts, backgrounds, margins, and padding. I also learned how to connect an external CSS file to my HTML page.

Lab 05: Website Design

In Lab 05, I evaluated the Baltimore Ravens website. I learned about website organization, accessibility, and the CRAP design principles: contrast, repetition, alignment, and proximity. I learned that a website should be easy to use and easy to understand.

Best Design Practices

I learned that a good website should be simple and easy to use. It should have clear headings, readable text, and colors that are easy to see. Links should be easy to find, and information should be organized. A website should also work on phones and computers. These design practices help make a website better for everyone.
